# 010. FS2 (GPH) — CX-2/CX-3

> Источник: референс-реализация `refs/src/BeTeP-STH_mft-scripts/fs2_update_ini.py`
> (+ enum mstflint `flint_base.h`); эмпирика — HP-пакет
> `refs/fw/Update_HP_…MT26448…/` и образы `refs/fw/cx-3/` (детекция —
> `005-detect.md`). Охват: CX-2, CX-3, CX-3 Pro.

## 1. Структура

Образ — последовательность секций **GPH** (16 байт, `fs2_update_ini.py:18-21`):

```
GPH: >IIII  →  type:u32, size:u32, param:u32, next:u32   (big-endian)
```

- `size` — в **DW**; полная секция = `16 + size*4 + 4` байта, где
  последние 4 байта — CRC секции (BE u32)
  (`fs2_update_ini.py:80-90`).
- GPH-цепочка стартует @ `FS2_BOOT_START = 0x38`; CRC-16 целого образа
  (полином `0x100B`) — @ `0x22` (`FS2_CRC_OFF`, алгоритм — `025-crc.md`,
  тот же, что FS3/FS4).
- Типы секций (`fs2_update_ini.py:21`, enum в mstflint —
  `flint_base.h:310-321`, `H_FW_CONF = 9` — `flint_base.h:316`):

| type | имя | содержимое |
|---|---|---|
| 0 | UNKNOWN | — |
| 1 | DDR | DDR-код |
| 2 | CNF | конфигурация |
| 3 | JMP | jump-код |
| 4 | EMT | emulator |
| 5 | ROM | option ROM |
| 6 | GUID | GUID |
| 7 | BOARD_ID | ID платы |
| 8 | USER_DATA | пользовательские данные |
| 9 | **FW_CONF** | **zlib-сжатый ini** |
| 10 | **IMG_INFO** | **TLV-записи (PSID и пр.)** |
| 11 | DDRZ | сжатый DDR |
| 12 | HASH_FILE | хеши |
| 13 | LAST | маркер конца |

- `IMG_INFO` — последовательность TLV-записей `IIT`
  (`fs2_update_ini.py:98-116`); **PSID хранится в TLV внутри IMG_INFO**
  (`self.psid_offset`, `fs2_update_ini.py:112-116`).
- device_id и PSID читаются из `IMG_INFO`/`dc.ini` (`adapter_dev_id`,
  `PSID`), а **не** из `FW_BOOT_CFG`.

## Приложение: эмпирика HP-пакета (`refs/fw/Update_HP_…MT26448…/`)

Состав пакета (сжато; сырой листинг — git-история док 10 §2.2):

| Файл/каталог | Что это |
|---|---|
| `firmware-image.bin` (0xa47ac) | FS2-образ (ver@0x24 = 0x0) |
| `CX3_EVB_A1.ini` | FS2-ini от **iniprep** («Generated automatically by iniprep tool … from ./cx3_socket_evb.prs»; `[PS_INFO] Name = CX3_EVB_A1`, `[ADAPTER] PSID = MT_1010110001, adapter_dev_id = 0x1003` — CX-3) |
| `fw-ConnectX2-rel.mlx` | **не бинарь, а Perl-скрипт TEMT** (`<section name="TEMTParameters">… <PERL> package main; …`) — шаблон обновления для `mlxburn` |
| `mlxburn.exe`, `flint.exe`, `mstflint.exe`, `mic.exe`, `t2a.exe` | инструменты |
| `ConnectX_Flexboot_*_ROM-3.4.000.mrom/` | option ROM'ы |

Вывод: FS2-era workflow = `mlxburn` + Perl/TEMT-скрипт; `mlxburn` в OSS
mstflint **отсутствует** (только в закрытых/старых MFT).
