## 1. Цикл замкнут, оба канала (C-RA3/C-RA4 закрыты)

Хост сеет magic `0x44554D31` + адрес в резерв (сл 0x8c5/0x8c6, CR
0x2314/0x2318 — **только резерв**: инлайн-зона волатильна, reg-трафик
сбрасывает посев, R-A2), триггер = любая рег-команда (ICMD GET MTRC_CAP
0x9040), H0 @dc 0xd3850 (`040`) → параметризованный стаб → ответ:

- **C** = emit7-событие rt **0x00aeb83b** (7 парамов r5..r11 = d0..d5 +
  эхо адреса; трейсер armed);
- **B** = 7 слов в резерв с базой CR 0x2320 (READY = magic-эхо сл 0x8c8 +
  d0..d5 0x8c9..0x8ce; poll VSEC).

6 слов/триггер без reflash, 3 класса ground-truth бит-экзакт (ro-data
SHA-256 K-таблица @rt 0xB19850, код стаба, RAM self-read 0x2314).

## 2. Режим-факты и эмпирика

- **Режим-факт (эрата потребителям): окно хендлера смаплено на
  host-VSEC вид только при вооружённом SET_ITRACE** (mask 0x4000000,
  level 1) — 6-модовая матрица (ra4 §«Ключевая находка»): driver-bound
  без арма — окно мертво (посев живёт, ответа нет). Рабочий режим
  обоих каналов: driverless (vfio) + arm (`045` §1). Детур-даунгрейд
  D2-класса и будущие B-потребители обязаны армить окно до посева.
- **cmp op0x38 sel=eq32 на Lx 14.32 работает** (гипотеза L0 подтверждена
  live: негатив 163.8 с — 0 событий, позитив — K-константы бит-экзакт);
  op36-запас (86 свидетелей) не понадобился, но билдер держит обе ветки
  (`--cmp {op38,op36}`). Мнемоника — `cmp38_eq32` (скилл `irisc-asm`;
  funct5≠2 → trap CPU).
- **ld.d из image-региона (rt ≥ 0x800000) доказан live** — первый
  триггер = дискриминатор (K-таблица), byte-swap нет (естественный
  BE). Код и ro-data делят один класс риска ld.d-from-image.
- **NV-override LINK_TYPE=ETH переживает банк-burn** и глушит
  boot-default VPI: lspci [0200] при VPI-байте 0x07 в обоих банках
  (rb-проверяемо); переключение владельцем (14 окт, t2b1→t2d1),
  mstconfig `LINK_TYPE_P1`. Откат — `mstconfig set LINK_TYPE_P1=IB(1)`
  + ребут.
- **Трейсер live-drain рендерит OUR-события 4 парамами** (дедуп
  mid-DMA) — вердикты только по офлайн-декоду raw-ринга (снят на
  SIGINT). Голый MTRC_CAP-триггер скрэтчит сл 0x8c9..0x8cc (data-зона
  регистра) — на хите стаб перезаписывает (сток-вызов первым, форма
  v3 — `040`).
- **Прямой mstreg PTYS → ICMD operational error** (синдромы
  0x49B0F2/0x7CD836, синтаксис верный — MTRC_CAP тем же инструментом
  чист); биты 56G/100G читаются драйверным рендером (ethtool:
  56000baseKR4 + 100000baseKR4/SR4/CR4/LR4 в Supported+Advertised при
  lcl[0]=0xfb). Причина синдромов не исследована — won't-fix (владелец
  2026-10-17, вне скоупа).
- **Инструменты/якоря**: `mlxscope dump {seed,trigger,read,clear,run}`
  (poll 2 с; write-гвард 0x8c5..0x8ce);
  `scripts/probes/cx4lx-dumpcycle/build_dump_ra3.py` (20 гейтов,
  `--chan {c,b}`, оба cmp, детерминизм ×2). Образы:
  `cx4lx-dump-ra3c.bin` md5 `be857b92dd05b85473f5e02e28c90b1e`
  (банк B), `cx4lx-dump-ra3b.bin` md5
  `3fccc48cdfe06ffe77d1507886cb7140` (банк A; перезаписан раундом-2 —
  бит-воспроизводим билдером, §3); burn `--no_fw_ctrl -y`, ребут
  активации между банками. Сло-бюджеты: C 20/24 (кейв 0x31cba0),
  B-сплит 26/34 (фрагмент 0x31cb70 9+мост).

## 3. Итерация 2 — R-A4b generic exec: ОТРИЦАТЕЛЬНЫЙ РЕЗУЛЬТАТ (2026-10-17)

- **Exec-циклы недостижимы**: посев ≤10 сл (сл 0x8c6 = N,
  0x8c7..0x8d0 — слова; `dump exec --words… [--expect]`,
  readback-verify ДО триггера) + copy-loop стаб (R-A1 §2 + отклонения,
  кейв 23/24 `--copydone on` / 22/24 off, фрагмент-буфер 0x31cb70):
  любой **armed**-триггер через хук (включая голый, без посева) клинит
  CMDIF — rc=124 @120–150 с, wedge 4/4 на четырёх загрузках; BMC power
  cycle — полное восстановление ×4. **Без арма всё чисто** (E0-негатив
  12.4–12.8 мс, зона нули; штатная работа карты не затронута).
- **Бисект (координаторский ребёрн off-варианта)**: tail-shift/маркер
  исключён — off (ra3c-геометрия хвоста) клинит так же → класс
  **head/armed** (тело пещеры после cmp + armed-окно, либо
  armed-механика с хук-сайтом; на миссе тело не исполняется —
  статическое противоречие; механизм FW не установлен). P1–P3 не
  выполнялись; P4/COPY-DONE N/A (пре-авторизованная деградация).
  Диагностический образ — вне аддендума; владелец 2026-10-17:
  зафиксировать, не копать.
- **Эрата-дополнение к armed-эрате** (§2): для copyloop-класса образов
  (chan g) голый armed-триггер не пускать (wedge); негатив-контроль —
  только unarmed-форма (E0).
- **Банки (факт)**: burn пишет НЕактивный банк
  (`docs/850-howto/100-cross-flash-ops.md` §7.1) — round-2 лёг в A:
  **A = ra4b-off (АКТИВЕН), B = ra4b-on**; ra3b перезаписан,
  бит-воспроизводим билдером (md5 `3fccc48c…`, якорная цепочка
  no-fw-backup цела). Владелец 2026-10-17: банки не трогать. Образы:
  ra4b-on md5 `016db98237705566f824c17f29405b4a`, ra4b-off md5
  `184ea4ef51ca56d37120fa62b1672425`; билдер `--chan g` +
  `scripts/probes/cx4lx-dumpcycle/ra4b_payloads.py` (P1–P4 листинги,
  decode-verify, детерминизм ×2 оба copydone); `mlxscope dump exec`
  (гварды 1..10 слов, clear до 0x8d0).
- **Диспозиции Lx-хвостов (владелец 2026-10-17)**: (1) переменный N —
  supersession-аргумент (generic exec вместо loop-стаба) отпал; пункт
  остаётся открытым/непокрытым; (2) mstreg PTYS-синдромы — won't-fix
  (§2); (3) cx4lx-профиль — live-формы `cmp38_eq32`/`or`/`csr.w`
  внесены (+3); base-zero `st.d` остаётся 'assumed' (P4 не выполнялся).
- Переход к CX-5 (фаза X) — **отложен** владельцем (2026-10-17).
