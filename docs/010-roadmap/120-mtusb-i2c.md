# Аналог MT-USB: out-of-band доступ через I2C (CH341/347)

Штатный MTUSB-1 — USB-to-I2C адаптер Mellanox: `mst status` →
`/dev/mst/mtusb-1` («USB to I2C adapter as I2C master»), через него
работают `mstflint q`/`burn` (ограничение MFT-doc: до 45 мин,
`-no_flash_verify` для ускорения). I2C-интерфейс карты — штатный
out-of-band/отладочный канал (programming-manual §1.2.1.3, p. 28:
out-of-band access / HW debug / Mellanox debug tools, slave-адрес 0x48,
master/slave, две шины на редундантность).

Стартовое положение (уже в репо): userspace I2C-мастер CH341
`scripts/ch341i2c.py` (pyusb; bulk-stream 0xAA, verify-by-read-back) +
контейнер `docker/ch341i2c.containerfile` + `make ch341i2c-run ARGS="…"`
(раздел «Трансиверы», 2026-10-04, журнал
`2026-10-04-ch341-programmer-bringup.md`); борты с CH341 в лабе
(PACBTECH, 1a86:5512). CH347 — второй кандидат (USB-UART+GPIO, I2C
bit-bang).

## Адаптеры: смена местами (цикл 2, 2026-11-22)

Цикл 2 планировался под CH341 (PACBTECH); фактически primary стал CH347T
(1a86:55db, `scripts/ch347i2c.py`, валидирован до 400 кГц, батч-режим 685.5 бл/с).
CH341A (чёрная flash-плата): до 3.3V-мода владельца исключён электрически
(ZIF13=SDA idle 1.88 В — LED-in-series топология; ZIF14=SCL 5 В). Мод
(VCC чипа → 3.3 В) дал: SCL (ZIF14, встроенный pull-up чипа) — чистые
3.2 В; SDA (ZIF13) осталась за LED-цепью — 1.62 В idle / 2.10 В под
картой; перепайка не потребовалась (прозвон цикла 3: ZIF13→нога 23,
ZIF14→нога 24 = выделенные I2C-пины SDA/SCL).
Маппинги ZIF зеркальны между платами: CH341A ZIF13=SDA/ZIF14=SCL (ноги 23/24),
CH347 ZIF13=SCL/ZIF14=SDA (ноги 11/12) — не путать при смене адаптера.

Вердикт CH341A (Task 6, цикл 3, 2026-11-22): **supported (read-path)** —
после мода (SCL 3.2 В, SDA за LED) карта отвечала через CH341A @20 кГц
(devid 0x020d + ≥2 полных ICMD-цикла живыми данными, профиль ch341);
completed-q не снят (120-с банда < длительности q @20 кГц, карта отвечала
до kill — таймаут-конфаунд, не отказ); write-limits не проверены
(функциональная карта). Прерывание mstflint внутри I2C ICMD write-burst
(пайп/timeout-SIGTERM) = flash-semaphore wedge (n=2) — лечение только BMC
power cycle; live-команды без пайпов, банд > ожидаемой длительности.
Дефолт продукта — CH347T. Детали: журнал `2026-11-22-mtusb-i2c-impl-task-06.md`.
